# DCIR and OCV (from RPTs)

DCIR and OCV extraction from Reference Performance Tests (RPTs). Data
collection is run on Neware cyclers; analysis currently runs in Voltaiq's
analytics studio.

- **Source data:** Voltaiq
- **Scripts here:** `voltaiq_scripts/` — template/reference copies of the
  Voltaiq analytics studio scripts used for DCIR/OCV analysis.
