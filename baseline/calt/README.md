# CaLT (Calendar Life Testing)

Master code output. Data collection is run on Neware cyclers; analysis
currently runs in Voltaiq's analytics studio.

- **Source data:** Voltaiq
- **Additional input required:** a "Storage time" spreadsheet (tracks how
  long each cell has spent in storage between measurement points) must be
  supplied alongside the Voltaiq data for the analysis to run correctly.
- **Scripts here:** `voltaiq_scripts/` — template/reference copies of the
  Voltaiq analytics studio scripts used for CaLT analysis.
